# god-tier-mini-prompts

A skill repo of **one-line "god-tier" prompt vectors** for coding agents —
each sentence so dense every word does work.

Built from all replies to
[Bootoshi's thread](https://x.com/KingBootoshi/status/2118803776387928228)
("I want a single sentence of vectors so juicy each verb, noun, and adjective
act like flavorful curry bombs"), plus Prompt Snacks and Notchbird's Banger
Prompts.

## Use

Drop this repo (or just `SKILL.md`) into your skills folder:

- Claude Code: `~/.claude/skills/god-tier-mini-prompts/SKILL.md`
- Codex: same layout under your Codex skills dir

Then either browse the collection or run the meta-prompt:

> Consider all the mini-prompts in this skill, pick the ones that would
> improve my idea/input/software the most, and apply them.

## Contents

`SKILL.md` holds everything: the meta-prompt, ~50 credited one-liners grouped
by Architecture, Debugging, Planning, Learning, Verification, and Steering,
plus the full expanded implicit-state-machine audit prompt.
