# god-tier-mini-prompts

A wide collection of **one-line power prompts** for coding agents —
single sentences so dense every word does work.

Drawn from across X/Twitter, Prompt Snacks, Notchbird's Banger Prompts, and
engineering blogs. Author handles kept as credit.

## Use

Drop this repo (or just `SKILL.md`) into your skills folder:

- Claude Code: `~/.claude/skills/god-tier-mini-prompts/SKILL.md`
- Codex: same layout under your Codex skills dir

Then either browse the collection or run the meta-prompt:

> Consider all the mini-prompts in this skill, pick the ones that would
> improve my idea/input/software the most, and apply them.

## Contents

`SKILL.md` holds everything: the meta-prompt, ~90 credited one-liners grouped
by Architecture, Debugging, Planning, Learning, Verification, and Steering,
plus the full expanded implicit-state-machine audit prompt and the
~35-prompt state-machine kit harvested reply-by-reply from the @steveruizok
thread (replies, quotes, and the replies on the quotes).
